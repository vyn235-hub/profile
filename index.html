05 / Dự án

Dự án cá nhân

Hai dự án tôi đã thực hiện tập trung vào trực quan hóa thuật toán sắp xếp và xây dựng hệ thống xác thực JWT SSO.

JWT SSO

Phát triển hệ thống JWT SSO cho phép xác thực người dùng bằng JSON Web Token (JWT), hỗ trợ đăng nhập một lần (Single Sign-On), quản lý phiên đăng nhập và phân quyền truy cập giữa các trang trong ứng dụng web.

  • JavaScript
  • Node.js
  • Express.js
  • JWT
  • REST API
  • HTML/CSS

Sorting Visualizer

Trực quan hóa các thuật toán Bubble Sort, Quick Sort và Merge Sort bằng Python và Pygame. Mô phỏng quá trình so sánh, hoán đổi phần tử, hỗ trợ sắp xếp tăng dần hoặc giảm dần và giúp người học hiểu rõ nguyên lý hoạt động của từng thuật toán.

  • Python
  • Pygame
  • Bubble Sort
  • Quick Sort
  • Merge Sort
